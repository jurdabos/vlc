Here are the steps to rotate `VLC_DEV_PASSWORD`:

## Password Rotation Steps

### 1. Update `.env`
```bash
# Edit .env and change VLC_DEV_PASSWORD to the new value
VLC_DEV_PASSWORD="new-SUPERSECURE-password"
```
### 2. Regenerate derived secrets
```bash
./scripts/sync-dev-secrets.sh
chmod 644 compose/.htpasswd
```
This updates:
- `compose/.htpasswd` (nginx basic auth)
- `connect/secrets/secrets.properties` (JDBC credentials)
- `db/init/020-vlc-password.override.sql` (Postgres role password)

### 3. Apply the new DB password
The `020-vlc-password.override.sql` file only runs on **fresh DB init**. For an existing database:
```bash
docker compose -f compose/docker-compose.yml --profile infra --profile ui --profile schema --profile producer up -d --build
docker exec -it timescaledb psql -U vlc_dev -d vlc -c "ALTER ROLE vlc_dev WITH PASSWORD 'new-SUPERSECURE-password';"
```
### 4. Restart affected services
```bash
docker compose -f compose/docker-compose.yml --profile infra --profile ui down
docker compose -f compose/docker-compose.yml --profile infra --profile ui --profile schema --profile producer up -d --build
```

### 5. Verify
```bash
docker exec -it timescaledb psql -U vlc_dev -d vlc -c "SELECT 1;"
```
