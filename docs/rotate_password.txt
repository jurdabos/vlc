Here are the steps to rotate `VLC_DEV_PASSWORD`:

## Password Rotation Steps

### 1. Update `.env`
```bash
# Edit .env and change VLC_DEV_PASSWORD to the new value
VLC_DEV_PASSWORD="REALNEWPASSWORD"
# The producers read PGPASSWORD, so keep it a reference, as in .env.example
PGPASSWORD=${VLC_DEV_PASSWORD}
```
### 2. Regenerate derived secrets
```bash
./scripts/sync-dev-secrets.sh
chmod 644 compose/.htpasswd
```
The script asks for the keyring master password, for the Alertmanager config. It updates:
- `compose/.htpasswd` (nginx basic auth)
- `connect/secrets/secrets.properties` (JDBC credentials)
- `db/init/020-vlc-password.override.sql` (Postgres role password)
- `monitoring/alertmanager/alertmanager.generated.yml` (Gmail app password, from the keyring)

### 3. Apply the new DB password
The `020-vlc-password.override.sql` file only runs on **fresh DB init**. For an existing database, apply the same file
by hand, so the password is never typed:
```bash
docker compose -f compose/docker-compose.yml --profile infra --profile schema --profile ui --profile producer up -d --build
docker compose -f compose/docker-compose.yml exec timescaledb psql -U vlc_dev -d vlc -v ON_ERROR_STOP=1 -f /docker-entrypoint-initdb.d/020-vlc-password.override.sql
```
### 4. Restart affected services
```bash
docker compose -f compose/docker-compose.yml --profile infra --profile schema --profile ui --profile producer down
docker compose -f compose/docker-compose.yml --profile infra --profile schema --profile ui --profile producer up -d --build
```

### 5. Verify
A local `psql` inside the database container checks no password, so test over the network and read the connector states:
```bash
docker compose -f compose/docker-compose.yml exec air-producer python -c "import os, psycopg2; psycopg2.connect(host='timescaledb', dbname='vlc', user='vlc_dev', password=os.environ['PGPASSWORD']).close(); print('login OK')"
docker exec compose-connect-1 curl -s 'localhost:8083/connectors?expand=status'
```
