20251221
Fixed Avro deserialization for lean-stack deployment.

The producers use Avro serialization with Schema Registry, which writes messages in the
Confluent wire format: 5-byte header (magic byte + 4-byte schema ID) + Avro binary payload.

For lean-stack deployment (profiles: infra, producer, alt-sink), Schema Registry is NOT running,
but the alt-sink consumers still need to deserialize Avro messages. The fix:

1. The sink containers now use `fastavro` to deserialize Avro binary directly
2. Avro schemas are loaded from local .avsc files mounted at /schemas
3. The consumer strips the 5-byte Confluent header and uses schemaless_reader

This allows the alt-sink profile to work without Schema Registry being up.

# Lean-stack deployment (VM-friendly):
# Set USE_SCHEMA_REGISTRY=false so producers use local Avro serialization
export USE_SCHEMA_REGISTRY=false
docker compose -f compose/docker-compose.yml --profile infra up -d
./scripts/bootstrap_kafka.sh --skip-connect
docker compose -f compose/docker-compose.yml --profile producer --profile alt-sink up -d

# Full-stack deployment (dev workstation):
# USE_SCHEMA_REGISTRY defaults to true, so no need to set it
docker compose -f compose/docker-compose.yml --profile infra --profile schema up -d
./scripts/bootstrap_kafka.sh
docker compose -f compose/docker-compose.yml --profile producer up -d
